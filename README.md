# Crescent Isle Useful Tool

FFXIV「蜃気楼の島 クレセントアイル」の南征編・北征編に対応した、探索支援用Dalamudプラグインです。

FATE／クリティカルエンカウント（CE）の監視、マジックポットの発生予想、宝箱・にんじん探索、通貨・経験値の計測、自動移動などを一つの画面にまとめています。

## 主な機能

### 南征編・北征編ダッシュボード

- 現在いるエリアに合わせたタブの自動選択
- 発生中のFATE／CE、進行率、開始・終了予想時間の表示
- デミアートマ、ノート、ソウルシャードなどの報酬情報表示
- 自動操作モードのON／OFF状態と現在のアクティビティを常時表示
- 「概要」「FATE・CE」「優先順位」「宝箱・探索」「支援ツール」「計測」「現在の設定」の7ページに機能を整理
- 画面幅に応じて1列／2列を切り替える、青色テーマのコンパクトなカード型UI
- 「現在の設定」では自動操作、移動、監視、宝箱、補助、バフ、ウィンドウ設定の保存値を、画面幅に合わせた折り返し表示で日本語一覧化

### FATE／CE移動支援

- 発生地点に最も近いエーテライトを選択
- 妖火の漁村エリア外のFATE／CEでは「妖火の漁村」を移動候補から除外
- Lifestreamとvnavmeshを利用したテレポート・マウント・経路移動
- 北征編CE 15件、FATE 13件を個別に有効／無効化
- CE／FATEの位置へマップフラッグを設定

### 北征編マジックポット

- 「隠されのマジックポット」「飛ばされのマジックポット」を検知
- ゲームが保持するFATE開始時刻を検知し、その後30分周期で次回発生を予想
- FATEをまだ観測していない場合は、最古時間179分・初回20分後のモデルで補完
- 次回発生予想が5分未満になると、FATE／CE参加中を除く実行中の移動を中断してマジックポットFATEを待機
- 「財宝誘導」バフを検知するとマジカルエリクサーを使用し、方角・距離と既知の候補座標から宝箱を推定して自動回収
- マジックポット宝箱の前では通常の青銅・白銀宝箱処理から分離し、マウントを降りて開封詠唱の完了を確認

### 宝箱・にんじん探索

- 周囲の青銅・白銀の宝箱とにんじんを検知
- 宝箱までの距離・位置を表示
- 取得可能な青銅／白銀の宝箱数と残数を表示
- 取得済みの青銅／白銀の宝箱数を表示
- 南征編は現在地から、北征編は探査隊の北部ベースキャンプから毎回同じ固定順で青銅・白銀の地上配置を巡回
- 北征編の固定巡回中に進行不能を検知した場合だけ残り経路を再作成し、同じ地点で再び進行不能になった場合のみ、その地点をスキップして巡回を継続
- 北征編の宝箱座標はゲーム内部の配置データから開始時に自動取得し、必要に応じて最寄りの魔導通路を利用
- 魔導通路の担当エリアをまたぐ場合は徒歩で直行せず、必ず魔導通路を経由
- 移動前にvnavmeshで到達可能な経路を検証し、空経路や長時間停止を検知した地点は安全にスキップして件数を表示
- 経路検索設定の「最大エリアレベル」（1～47）を超える周辺敵が実際の経路上にいる場合、その敵へ近づく区間を除外
- 北征編南西高台は内部レイアウトの乱気流座標から進入・退出し、高台上の宝箱をまとめて巡回
- 宝箱はマウントに乗ったまま開錠し、開封後はすぐ次の地点へ移動。現在のプレイヤーには出現していない配置地点は自動でスキップ
- 停止時に巡回位置を保存し、次回の開始操作で中断地点から再開（「最初から」で経路を破棄可能）
- トレジャーハント開始時にすっぴんの「マギ・トレジャーサーチ」を使用して残数を再計測し、完了後は変更前のサポートジョブへ復帰
- 地上の全座標巡回後、開始時残数・取得数・残数を照合し、地下空洞または未取得の残りを表示
- マギ・トレジャーサーチで判明した開始時の残り青銅数・白銀数を個別表示

### 計測・補助機能

- 1時間あたりの銀貨・金貨獲得量（常時計測）
- 1時間あたりの経験値獲得量（常時計測）
- ナレッジクリスタル付近まで自動移動してから、すっぴんの「たんきゅうしん」（Action ID 46606）で4種類の30分バフを一括更新（未付与・しきい値以下を常時監視し、北征編追加ジョブを含む元のサポートジョブへ復帰）
- Mob Farmerによる周辺エネミーの検知・戦闘支援
- FATE／CEの情報パネルと宝箱・にんじんのレーダー表示
- CIUTテーマでカテゴリ分けした設定画面と、「たんきゅうしん」専用バフ設定画面
- 自動操作設定を「基本設定」「南征編」「北征編」の3タブに分け、対象CE／FATEを同じ一覧形式で設定

## 自動操作モード

自動操作モードは、発生中のアクティビティへの移動と戦闘支援を自動化する任意機能です。

- メイン画面の「優先順位」タブで「マジックポット」「CE」「通常FATE」を任意の順に並べ替え
- 状態マネージャーの下に、現在の状況から次に実行する5ステップを表示
- 実行画面に検知中のFATE／CE件数、移動状態、依存プラグインの準備状態を表示
- 北征編で対象がない場合は「探査隊の北部ベースキャンプ」のエーテライト付近で待機
- 新しいアクティビティ発生時は、目的地に最も近いエーテライトを経由して移動
- FATE／CE完了後は移動を停止し、必ずデミデジョンで拠点へ帰還してエーテライト付近まで移動
- 完了通知が重複した場合や帰還処理が中断された場合は、デミデジョンの二重実行を防ぎながら帰還を再試行
- 移動が停止した場合は経路を再作成し、同じアクティビティで3回停止した場合は対象を一時除外して拠点帰還へ移行
- 自動操作、通常トレジャーハンター、マジックポット宝箱探索は同時実行せず、優先機能へ安全に切り替え
- アクティビティ完了時以外は、拠点およびデミデジョン到着地点の周辺でデミデジョンを実行しない
- VBMまたはBossMod Rebornとの連携、強制ターゲット設定に対応

自動化機能の使用可否や扱いは、利用環境のルールを確認したうえで各自の責任で判断してください。

## 必要なプラグイン

通常の情報表示だけであれば単体で利用できます。自動移動・自動操作モードを使用する場合は次のプラグインが必要です。

- Lifestream
- vnavmesh

自動移動の開始時にIPCやナビメッシュがまだ準備中の場合は、画面に待機理由を表示し、準備完了後に自動で処理を再開します。トレジャーハント開始時は移動処理の競合を防ぐため、自動操作モードを自動的にOFFにします。

戦闘AIの自動ON／OFFを利用する場合は、次のいずれかを設定します。

- Boss Mod（VBM）
- BossMod Reborn（BMR）

## コマンド

| コマンド | エイリアス | 内容 |
|---|---|---|
| `/ciut` | `/crescent`, `/crescentisle` | メイン画面を開く |
| `/ciut config` | `/ciutcfg`, `/ciutconfig`, `/crescentconfig` | 設定画面を開く |
| `/ciut auto [on\|off\|toggle]` | `/ciutauto`, `/crescentauto` | 自動操作モードを操作する |
| `/ciut buff` | `/ciutbuff`, `/crescentbuff` | ナレッジバフを更新する |
| `/ciut tp [pot\|ce\|fate]` | `/ciuttp`, `/crescenttp` | 対象の最寄りエーテライトへ移動する |
| `/ciutcmd flag-active-ce` | `/crescentcmd flag-active-ce` | 受付中のCEへフラッグを設定する |
| `/ciutcmd flag-active-fate` | `/crescentcmd flag-active-fate` | 発生中のFATEへフラッグを設定する |
| `/ciutcmd flag-active-non-pot-fate` | `/crescentcmd flag-active-non-pot-fate` | マジックポット以外のFATEへフラッグを設定する |
| `/ciut language <code>` | ― | 表示言語を変更する |

対応する言語コードは `en`、`de`、`fr`、`jp`、`uwu` です。

## インストール

Dalamudの「設定」→「試験的機能」→「カスタムプラグインリポジトリ」に次のURLを追加してください。

```text
https://raw.githubusercontent.com/Rowsai/Rowsai-Plugins/refs/heads/main/pluginmaster.json
```

プラグイン一覧を更新し、「Crescent Isle Useful Tool」をインストールしてください。
